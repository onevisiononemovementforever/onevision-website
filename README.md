# onevisiononemovementforever.com

Website of One Vision One Movement Forever (ONEVISIONONEMOVEMENTFOREVER LTD, NI744016).
A single self-contained page (`index.html`) served by GitHub Pages from the `main` branch.

- Daily quote and kindness challenge change at midnight in the visitor's time zone.
- The Join form posts to the Brevo form "One Vision members (website)" (list "One Vision members").
- Settings are in the `CONFIG` block at the top of the script in `index.html`.
